# FASE 2 · FRONTEND · Piezas sueltas de pantalla, reutilizables

> **Creada en:** Fase 1 · **Se llena en:** Fase 2 · **Estado actual:** vacía

Botones, tablas, etiquetas de estado, ventanas emergentes, campos de formulario.

Son piezas **genéricas**: no saben nada del mantenimiento. Un `Boton` sirve igual
para "Guardar orden" que para "Cerrar sesión". Esa ignorancia es lo que permite
reutilizarlas en todas las pantallas.

**Prohibido aquí:** consultar la base de datos. Reciben todo por `props`.
